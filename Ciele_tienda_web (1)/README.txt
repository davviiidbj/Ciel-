# Cielé — tienda de accesorios

Esta es la primera versión de la tienda web de Cielé.

## Cómo abrirla
1. Abre `index.html` en Chrome.
2. La tienda funcionará como una página web local.

## Para personalizarla
- Cambia el número de WhatsApp en `script.js`.
- Cambia los productos, precios y cantidades en el arreglo `products`.
- Más adelante podemos reemplazar las imágenes de ejemplo por fotos reales.
- También podemos agregar un panel de administración para modificar el inventario sin tocar el código.

## Publicarla gratis
La siguiente etapa puede ser subir estos archivos a un servicio de hosting gratuito y dejar Cielé disponible con un enlace público.
